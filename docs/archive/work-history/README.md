# Archived Working Documents

**Status:** Historical

This directory contains task runbooks and design notes retained for audit
traceability. It is not an active specification source. Current protocol and
runtime claims belong to the documents indexed by `docs/README.md`.

The underscore copies of tasks 35-41 were removed because they were
byte-for-byte duplicates of the hyphenated files. Task 34 retains both files
because they contain different content and require a future consolidation
decision.

Historical claims about Go P2P, DNS seeding, reward schedules, or audit results
must be verified against the current checkout before reuse.
